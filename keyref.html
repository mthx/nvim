Neovim Key Reference

Leader key is Space — which-key will show available bindings as you type

Essential Vim

iInsert mode (before cursor)
aInsert mode (after cursor)
o / ONew line below / above
EscNormal mode, clear search highlight
u / Ctrl rUndo / redo
.Repeat last change
:cmdCommand mode
:w / :qSave / quit
:wq or ZZSave and quit

Movement

hjklLeft, down, up, right
w / bNext / previous word
0 / $Start / end of line
^First non-blank character
gg / GTop / bottom of file
{ / }Previous / next paragraph
Ctrl d / Ctrl uHalf-page down / up
%Matching bracket
/patternSearch forward
n / NNext / previous match
*Search word under cursor

Editing

dd / yyDelete / yank line
p / PPaste after / before
cc / CChange line / to end
ciwChange inner word
ci" / ci(Change inside quotes / parens
di{ / da{Delete inside / around braces
xDelete character
~Toggle case
>> / <<Indent / dedent line
V then >Visual select then indent

Visual Mode

vCharacter-wise visual
VLine-wise visual
Ctrl vBlock visual (columns)
gqReflow selection

Find & Replace

Space ffFind files
Space fgLive grep (search in files)
Space fbBuffers
Space SpaceBuffers (alt)
Space fhHelp tags
Space fdDiagnostics
Space frResume last search
:%s/old/new/gReplace all in file

Inside Telescope: Ctrl-j/k to move, Enter to open, Esc to close

LSP (Code Intelligence)

gdGo to definition
gDGo to declaration
grReferences
giGo to implementation
gyType definition
KHover documentation
Space caCode action
Space crRename symbol
Space cdLine diagnostics
Space qDiagnostics list

File Explorer (Neo-tree)

Space eToggle file tree

Inside Neo-tree:

Enter / oOpen file
aAdd file/directory
dDelete
rRename
c / m / pCopy / move / paste
HToggle hidden files
RRefresh
?Show help

Completion (blink.cmp)

Ctrl n / Ctrl pNext / previous item
EnterAccept completion
Ctrl eDismiss
Ctrl b / Ctrl fScroll docs up / down

Windows & Buffers

Ctrl hjklMove between windows
:sp / :vspHorizontal / vertical split
Ctrl w qClose window
Ctrl w =Equalize window sizes
:bn / :bpNext / previous buffer
:bdClose buffer

Management

:LazyPlugin manager
:MasonLSP server manager
:LspInfoActive language servers
:checkhealthDiagnose issues
